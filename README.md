# YandeCode

Local-first agent harness for Claude Code: disciplined swarm orchestration, hybrid RAG over your repository, and persistent agent memory.

> Status: Phase 1 (Foundation). Not yet published to npm.

## Requirements

- Node.js 22+
- Claude Code installed and authenticated
- Git

## Development

```bash
npm install
npm test
npm run lint
npm run typecheck
npm run build
```

See `docs/adr/` for architecture decisions.
